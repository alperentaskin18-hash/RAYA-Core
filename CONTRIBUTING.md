# Contributing

Describe the user-visible problem and expected behavior in a review request. Use original material or document the source, applicable license and permission for any contribution. Keep credentials, private datasets and recordings outside the project.

Use Python 3.11 or newer. Run the acceptance tests with `python -m unittest discover -s tests -v`. The GUI tests need a display and the image tests need the optional images dependency. Include test evidence and specify which dependencies or devices were simulated. Update the source allowlist and dependency inventory for changes to the distribution. Report sensitive security issues privately as described in SECURITY.md.
