# Source provenance and inventory

The project-specific Python, PowerShell and Tk code was independently generated for this project with Codex. The tests use original synthetic text, goal records, images and local server responses. The manual inference fixture generates its weights from code. The avatar consists of original Tk canvas geometry.

The Python standard library supplies the headless CLI services. SQLite, Tcl/Tk and Windows services are provided by the platform. Optional image features use Pillow. A local model server and model weights are separately supplied by the operator. Review the terms of the selected server, model and any binary dependencies before redistributing them. sbom.cdx.json inventories direct source-package prerequisites and selected validation components with their observed versions and license identifiers.

The source packager enumerates the distributed files. Original project materials include the application in raya/, synthetic fixtures and acceptance checks in tests/, packaging and verification utilities in tools/, CI configuration and the accompanying documentation. Third-party actions in the CI configuration are referenced by commit. Their code is obtained by the CI runner.
